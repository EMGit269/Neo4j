## 实际核对到的事实

- 两部分在原始 `.3dm` 建筑网格中已有独立屋顶面，Z 分别为 **6 m / 3 m**。
- 原模型的分界位置有 3 个竖直网格面，其 Z 范围分别为 0–6、0–6、0–3。
- 因此当前地图的分界有源几何依据；不是配准新增的线、当前选框裁断，或地图瓦片边界。
- 两部分原来的 `footprint_requires_review` 均为 false。旧检查关注非流形、多个水平面、
  明显重叠等，无法发现两个拓扑分别有效、但可能由规则分块产生的独立体。
- 全窗口初步扫描发现 917 对近接轮廓有超过 4 个模型单位的近共线边界；其中 545 对近 X 定值，
  325 对近 Y 定值。X 方向聚类位置间距中位数约 274.4 模型单位，Y 约 234.85，呈规则网格特征。
  **这些是疑似接缝候选，不是确认破损建筑数，也不是自动合并清单。**

扫描采用距离 0.05 模型单位、临时精度网格 0.05、坐标轴跨度 0.11 的诊断条件，
没有对原始数据或当前分析几何做吸附、改高或合并。完整参数与原网格核验见 `diagnosis.json`。

## 原因判断与影响

证据强烈提示原模型或上游数据经历了规则网格分块，当前提取按三维网格完整共边拆分，
保留了这些几何部件；原始制作者具体采用哪种软件和流程尚不能确定。
同一外观完整轮廓的各块甚至带不同模型高度，不能将这些高度直接作为真实高差。

这也进一步说明 22,700 是建筑几何候选数，不能当作已核实的建筑栋数。
疑似切块会影响单栋面积、形态、邻接关系和高度统计，几何有效检查不能替代建筑实体识别。

合理的后续清洗要结合规则分块线、轮廓衔接、可靠外部轮廓/影像和高度来源，
输出可追溯的合并建议。不能把所有相接建筑做 union，也不能只在地图上隐藏线来宣称数据已修复。
当前独立建筑 SHP 在该处与模型逐栋轮廓对应较差，不能直接按最大重叠自动替换并复制高度。
初始阶段仅做来源诊断；用户随后授权修复合并。当前已经完成下述算法修复，
未将合并结果称为经实测确认的建筑实体，也没有改写模型原始高度。

## 修复方法与边界

实现：`src/urban_fabric/seam_repair.py`，执行：`scripts/repair_building_seams.py`，
完整阈值配置：`configs/building-seam-repair.yaml`。

1. 在全域 111,347 个源组件中识别近共边候选，从重复位置及跨越多个地点的支持证据推断网格线。
   使用全域可把窗口边缘同一组的外部组件一并找回，避免合并结果被研究边界再次切断。
2. 要求分界靠近已识别的规则网格线，两端的外轮廓方向均能连续衔接，转角不超过 15°。
   角点接触、孤立共墙、远离网格和外轮廓明显不连续的对象不直接合并。
3. 优先对原始面做精确并集。存在数值小缝隙时，仅对候选组内近重合顶点/边互相吸附；
   必要时以 0.05 模型单位的局部精度网格回退。其他建筑不移动。
4. 每组要求结果为有效单面，面积对称差不超过原组面积的 0.2%，
   两侧填充轮廓需相互落在 0.12 模型单位缓冲范围内。保留凹形与庭院，不用凸包补形。
5. 最多迭代 4 轮，单组最多 16 个源组件；证据不足或超过变形阈值的对象保留待核。
6. 合并得到完整轮廓后恢复 WGS84，再转入现有 SHP 的自定义真实米制投影，
   重算面积、周长、momepy 形态指标及窗口内覆盖面积。

阈值中的模型单位仅用于源网格证据与误差限制；不是把模型 XY 重新解释成地面米。
这是一套保守、可追溯的算法规则，仍可能留下少量未修复对象或需要人工确认的合并。

## 数据文件与地图

新数据位于 `data/suzhou_old_city/repaired/`，原始 Rhino、原提取与原配准数据保留。

| 文件 | 内容 |
|---|---|
| `buildings.parquet` / `building_metrics.csv` | 当前候选轮廓与重新计算的真实投影指标 |
| `suzhou_old_city_repaired.gpkg` | 当前轮廓、源块高度几何、合并组与待核层 |
| `source_membership.csv/parquet` | 每个源组件对应哪一个合并后对象，保留原 ID/高度 |
| `height_parts.parquet` | 完整源块几何与高度，可保留分块竖向信息 |
| `remaining_review.parquet/csv` | 480 个仍有疑似接缝待核的候选轮廓 |
| `repair_report.json` | 来源指纹、网格证据、阈值、覆盖变化和写入读回结果 |
| `all_model_pair_decisions.parquet` | 全域每轮候选边的判断和理由，可审查合并依据 |
| `all_model_merge_events.json` | 全域每轮合并/保留事件 |
| `screenshot_before_after.png` | 用户截图位置合并前后比较 |
| `repair_sample_contact_sheet.png` | 小/大、两块/三块、凹形轮廓等实际组样例 |

623 个合并组均标记为算法修复、尚未实测确认；618 个冲突组的 `height_extent_m` 留空，
提供 `model_height_min_m`、`model_height_max_m` 和原高度列表。
`estimated_prism_volume_m3` 同样在高度冲突时留空；
`source_parts_prism_estimate_sum_m3` 仅为各源块原高度乘面积的求和，不等于已验证的整栋体积。

POI 地图与地理叠合地图默认加载修复后轮廓，可开启合并前轮廓、已合并组和剩余待核轮廓。
POI 与建筑仍只是同图叠合，没有借此自动赋予建筑功能或通行关系。
