# 苏州模型坐标恢复与真实地图叠合

核验日期：2026-11-24。原始 Rhino 与下载的 SHP 均未修改。

后续分缝修复已完成：当前建筑轮廓/指标使用 `data/suzhou_old_city/repaired/`，
22,073 个候选。本文 `georeferenced/` 中的 22,700 个候选和统计保留为配准后、合并前的记录。
转换关系及参考道路/水系保持有效，详见 [分缝修复](building-seams.md)。

## 结论与原因

Rhino 声明单位为米，但其 XY 实际对应 **WGS84 经纬度 × 100000，再减去固定偏移**。
这使 X、Y 在地面上的比例不同；给模型直接指定 UTM 或套用一个米制平移均不正确。
从下载的 `gis_osm_roads_free_1.shp` 找到了 66,981 条对应线段，恢复关系为：

```text
WGS84 经度 = (模型 X + 12035810.241736354) / 100000
WGS84 纬度 = (模型 Y +  3128482.8565913253) / 100000

模型 X = WGS84 经度 × 100000 - 12035810.241736354
模型 Y = WGS84 纬度 × 100000 -  3128482.8565913253
```

这是特定模型经验证的转换，不能推广到其他 Rhino 文件。
Z 未套用 XY 比例；GIS 几何输出为二维，模型高度单独保留为未经测绘核实的属性。

## SHP 的两种坐标系统

下载目录：`source_files/苏州shp新/`。

- OSM 道路、水系、POI 等 SHP 声明为 EPSG:4326 / WGS84。
- `Suzhou_Buildings.shp` 声明为自定义 `UTM_Modified` 投影，保留完整 PRJ/WKT：

```text
+proj=tmerc +lat_0=0 +lon_0=120.5445743 +k=0.9996
+x_0=500000 +y_0=0 +datum=WGS84 +units=m
```

它不是 EPSG:32651（后者中央经线为 123°）。当前指标与 GeoPackage 使用原 SHP 的自定义投影，
地图 GeoJSON 使用 WGS84。GeoPandas 中用 `to_crs` 转换坐标，不能仅 `set_crs` 更换标签。

## 窗口保留，真实尺寸修正

保留用户选定的模型范围 `[23000, 0, 29000, 5000]`，建筑候选仍为 22,700 个。
配置中的 `bbox_local_m` 是兼容历史代码的键名，数值实际为模型坐标，不能继续解释为地面米。

| 项目 | 本次结果 |
|---|---:|
| 西 / 东经度 WGS84 | 120.5881024174 / 120.6481024174 |
| 南 / 北纬度 WGS84 | 31.2848285659 / 31.3348285659 |
| 窗口中线附近东西 / 南北距离 | 5711.65 / 5543.74 m |
| 自定义投影中的面积 | 31.638590 km² |
| 椭球面面积 | 31.663876 km² |
| 窗口内建筑轮廓并集面积（投影） | 8.883904 km² |
| 建筑候选轮廓覆盖率 | 28.0793% |

投影面积与椭球面积略有差异，符合该投影的比例因子；指标采用同一投影口径。
原来的“6×5 km、30 km²”只对应模型坐标，应停止作为真实面积使用。
面积、周长、momepy 紧凑度/伸长比/矩形度以及棱柱体积估算已在真实投影下重算。
旧指标在新导出中加 `legacy_local_` 前缀，便于追溯；它们的历史 `_m` / `_m2` 名称不再表示实地单位。

## 配准与质量验证

1. 对全域模型道路和 OSM SHP 道路建立无向线段向量指纹。
2. 显式检验“经纬度 × 100000”的假设，用平移众数和起终点共同筛出对应线段；去掉重复匹配。
3. 用完整 0.02° 空间格子划分参数拟合与验证区域。52,985 条线段估计偏移，13,996 条线段验证。
4. 检查两端经纬度的椭球距离残差；这些对应几何几乎完全复原。
5. 将模型、独立建筑 SHP、OSM 水系和地标放在同一投影中叠合；查看拙政园附近道路。
6. 逐层写入后读回 GeoPackage，检查数量、ID、CRS 和边界；窗口内建筑 ID 唯一、轮廓有效。

**近零残差说明找回了共同来源的坐标关系，不能理解为纳米、厘米或测绘精度。**
匹配筛选使用了几何一致性，不是对任意道路的盲测，也没有用实测控制点检验现实位置。

建筑 SHP 与模型不是逐栋相同的轮廓：最近质心距离中位数约 6.97 m，
描述性最近质心配对的轮廓 IoU 中位数约 0.281，仅 1,337 对高于 0.8。
最近质心配对没有证明建筑实体相同；差异可能涉及来源、年份、分割和制图方式，原因尚未核实。
不能以这次坐标恢复为由直接把 SHP 轮廓、模型高度和 POI 功能逐项拼接。

重投影后对 22 个出现数值或拓扑无效的候选轮廓做了修复，并保留逐对象标记。
原有建筑分割待核标记保留；道路来源线还没有经过可路由网络的拓扑验收。
建筑 SHP 的 `DocUpdate=2019-12-31`、ArcGIS XML 和模型保存时间不等于实测日期。

## 当前可用文件

当前有效地理数据全部位于 `data/suzhou_old_city/georeferenced/`：

- `suzhou_old_city_projected.gpkg`：9 层，含窗口、模型建筑、完整/裁切场地线、参考建筑、OSM 道路/水面/点和面 POI。
- `buildings.parquet`、`building_metrics.csv`：重算后的真实投影指标，完整建筑轮廓。
- `analysis_window_wgs84.geojson`：真实研究范围，可用于网络地图和 POI 查询。
- `*_wgs84.geojson`：相应网络地图图层。
- `road_control_segments.parquet`：校准对应线段、来源 ID、拟合/验证分区和残差。
- `building_reference_comparison.parquet`：建筑 SHP 描述性配对比较，不是实体匹配结果。
- `georeferencing.json`：转换正反公式、完整 WKT、SHP 家族 SHA-256、验证统计和限制。
- `map.html`、`georeferencing_preview.png`：交互叠合图与静态核验图。

原 `suzhou_old_city_local.gpkg` 和全域提取继续作为模型原坐标记录保留，不再作为地面米制指标入口。
参考 SHP 图层包含窗口周边 500 m 背景，不能把整层数量直接当作窗口内数量。
QGIS 可直接打开新 GeoPackage；不要覆盖其自定义投影。
