# 苏州古城区预研究安排

当前窗口：模型 X=23000–29000、Y=0–5000，真实投影面积约 31.6386 km²。
模型 XY 不是地面米制坐标。以下是后续研究安排，尚未执行设计优化实验。

## 当前基础

原窗口含 22,700 个建筑几何候选，分缝修复后为 21,827 个；另有 3,730 条道路来源线及水系、绿地和铁路。
944 个候选涉及跨源或内部多部件接缝合并，重复网格疑似分缝待处理数为 0。
高度有差异的合并组取源块最高模型高度，保留逐块高度；最高值未经测绘核验。
建筑边界处保留完整几何，覆盖面积只计窗口内部分。OSM POI 筛选后保留 1,785 条。
全域数据仍保留，可在后续路径分析中扩展边界。

## 先完成的数据工作

1. 地理坐标已通过配套 SHP 恢复；继续独立复核位置，核对数据年份和高度来源。
2. 在古城区抽样复核网格单元对应的建筑实体，区分相接建筑、院落、裙房和模型碎片。
3. 识别道路中心线、边界线、交通岛等表达，再选择中心线提取和拓扑修复方法。
4. 核对桥隧、入口、围墙和通行条件；几何相交或邻近不自动当作通行边。

## 可以开展的预研究

先做轮廓质量、面积和形态描述，比较不同质量筛选规则对结果的影响。
模型高度可作描述变量，但需说明 3 m 量化特征，不能直接认定为测绘高度。
在明确街区分析单元后，可比较建筑形态组合及建筑—水系—公共空间的几何关系。

道路模型核验后，才开展局部通道变化、绕行影响和有限干预方案搜索。
每个实验需要固定输入、目标、预算、对照算法和验证口径，并明确候选通路的可实施条件。

Neo4j 用于对象关系、来源和方案管理；算法可在 Python / NetworkX 中运行。
现有研究无需先训练 GNN；是否使用学习方法取决于明确任务和可用的独立标签。
